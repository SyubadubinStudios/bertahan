## Sekilas

- **Genre:** survival aksi orang ketiga, bergaya lucu dan menarik
- **Platform:** Windows, Linux, macOS (.NET 10, GPU DirectX 12, Vulkan, atau Metal)
- **Pemain:** 1
- **Bahasa:** Indonesia
- **Dibuat oleh:** Ariana Mischa Fadhila dari Subadubin Studios
